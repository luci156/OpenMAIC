# IELTS Band Calibration

Use this as the shared level-setting method for IELTS lessons and practice. Combine it with the relevant skill-specific coach when the request focuses on Listening, Reading, Writing, or Speaking.

## Establish the target

1. Read the selected IELTS range and target band from the session or course context before planning.
2. If the user names a target band inside the selected range, use that target. Otherwise calibrate to the selected range and make the intended level clear.
3. If the user requests a band outside the selected range, do not silently ignore either instruction. Explain the conflict briefly and ask whether to change the selected range or keep the current range.
4. Do not infer a learner's real IELTS score from one prompt or exercise.

## Calibrate the learning material

- At bands 3.0–5.5, use concrete situations, common vocabulary, short clear instructions, visible models, and guided practice. Increase difficulty gradually within the requested target.
- At bands 5.5–7.0, use broader academic and everyday vocabulary, paraphrase, connected ideas, multi-step strategies, and moderate inference while explaining unfamiliar task demands.
- At bands 7.0–9.0, use precise academic language, nuanced claims, dense but readable passages, subtle paraphrase, and demanding inference. Prefer precision and control over obscure vocabulary.
- These are teaching choices, not exact official descriptor boundaries. Never claim that a text or answer guarantees a particular IELTS score.
- Progress from supported examples to independent practice. Keep distractors and task complexity appropriate to the target.

## Language and integrity

- Write student-facing slides, passages, questions, model answers, and practice directions in English by default. Use another language for teacher-facing explanation only when the user requests it or needs clarification.
- Create original practice. Do not present generated material as an official or copied IELTS test.
- When estimating performance, name the evidence and uncertainty; do not present an automated estimate as an official examiner score.

## Finish

Check that the target band, language, vocabulary load, task difficulty, examples, and feedback agree across the whole lesson. If another IELTS coach is active, let that coach determine the task-specific method and use this skill only for level calibration.
