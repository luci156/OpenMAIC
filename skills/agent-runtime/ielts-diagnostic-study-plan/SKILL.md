# IELTS Diagnostic & Study Plan

Turn the learner's goal and available evidence into a practical plan. Apply `/ielts-band-calibration` and use `/zone-of-proximal-development` for a guided diagnostic-and-practice lesson when appropriate.

## Establish the starting point

- Reuse information already provided. Ask only for missing details that change the plan: target band, test date or study period, current results or self-assessed strengths, weakest sections, and realistic weekly study time.
- Do not invent a baseline. If no reliable results are available, offer a short diagnostic across the relevant skills and label it as an informal starting check.
- Prioritize the learner's goal and constraints. Do not assume all four skills need equal time.

## Build the plan

- Set a small number of measurable weekly outcomes, practice activities, and review checkpoints.
- Rotate focused practice with spaced review of recurring errors and vocabulary. Include timed practice progressively rather than making every early activity a full test.
- Select materials and task difficulty using `/ielts-band-calibration`. Include recovery time and a fallback for missed study sessions.
- Explain how the learner will know whether to continue, revisit a skill, or increase difficulty. Avoid promising a band increase by a fixed date.
- Keep the plan in English when it is learner-facing by default; use the learner's language for clarification when requested.

## Deliver

Give a concise schedule with priorities, estimated time, task type, and a checkpoint. State assumptions clearly. If the deadline is unrealistic for the evidence available, say so kindly and offer the most useful achievable plan rather than guaranteeing the target.
